Frequently Asked Questions

What database credentials does WorkforceIQ use?

WorkforceIQ runs on local MySQL 8/9 with settings defined in config.properties (Default user: root, password: 12345).

How do I start the application?

Run a single command: mvn clean package exec:java or .\mvn clean package exec:java. The Jetty server starts on http://localhost:8080.

What demo accounts can I log in with?

You can log in as Admin (admin@workforceiq.com / admin123), Manager (manager@workforceiq.com / manager123), or Viewer (viewer@workforceiq.com / viewer123).
